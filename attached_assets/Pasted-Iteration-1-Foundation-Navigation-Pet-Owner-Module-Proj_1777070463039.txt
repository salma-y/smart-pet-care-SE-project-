━━━ PART A: GLOBAL FOUNDATION ━━━

1. Design System Setup

   - Build a top navigation bar with: Logo, main nav links (Pet Owner | Veterinarian | Service Provider | Marketplace | Admin), notification bell icon, user avatar dropdown
   - Build a collapsible sidebar for module-specific navigation
   - Create a universal footer with links and branding

2. Landing / Home Page
   - Hero section with headline, subheadline, and two CTAs: "I'm a Pet Owner" and "I'm a Professional"
   - Features overview section (3 modules preview cards)

   - "How It Works" 3-step section

3. Authentication Pages (UI only — no backend)
   - Login page (email/password + social icons)
   - Registration page with role selector: Pet Owner | Veterinarian | Service Provider
   - "Forgot Password" page

Pages to build:

8. Appointment Booking Page

━━━ DELIVERABLE NOTES ━━━
- All pages should be connected via navigation (no dead links)
- Use realistic dummy data (pet names, vet names, dates)
- All forms should have proper validation UI (error states, required field indicators)
- Responsive on mobile and desktop
- Prepare folder/file structure ready for PHP integration later (e.g., separate data objects in JS that can later be replaced by API calls)
