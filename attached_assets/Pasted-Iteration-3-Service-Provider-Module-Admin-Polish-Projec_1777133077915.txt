1. Sitter / Walker Dashboard

   - Certification badges display — Function #26 UI

2. Service Area Setup Page (Function #22)
   - Map placeholder with drawn geofence zones (visual only using SVG overlay or static map image)

3. Booking Management Page
   - Booking request cards: pet info, owner name, date/time, service type

4. Tiered Pricing Setup Page (Function #23)

   - Duration multiplier selector

   - Multi-pet discount rules (e.g., +1 pet = -10%)

5. Active Walk / Session Tracker Page (Function #24)

   - High-priority structured form: incident type, description, severity selector
   - Photo upload UI
   - Send to Owner + Send to Admin toggle

7. Check-In / Check-Out QR Page (Function #29)
   - QR code display (static generated image placeholder)
   - "Scan to Check In" instruction card
   - Check-in / check-out timestamp display
   - Confirmation status badge

8. Behavioral Briefing Page (Function #30)
   - Pre-service brief card: handling instructions, warnings, emergency contacts
   - Read & Acknowledge button (required before booking activates)
   - Allergy / medical notes (limited view — owner-controlled)

9. Provider Earnings & Analytics Page (Function #32)
   - Earnings chart (weekly / monthly toggle — bar chart)
   - Pending vs. paid breakdown
   - Mileage log table (simulated) with tax-deductible total
   - Payout history list

10. Provider Certification Page (Function #26)
    - Certification upload form: cert type, issuing body, expiry date, document upload
    - Verification state machine UI: Submitted → Under Review → Verified → Badged
    - Active certifications display with expiry alerts

11. Review System Page — Sitter View (Function #31)
    - Reviews received (owner ratings of sitter)
    - Reviews given (sitter ratings of pets/owners)
    - Overall rating summary card
